# Студия голоса · Silero V5

Локальное Windows-приложение: слово или текст → WAV.

## Установка и запуск

1. Скачайте проект через **Code → Download ZIP** на GitHub.
2. Распакуйте ZIP в отдельную папку с правом записи. Не запускайте из архива.
3. Дважды щёлкните **run.bat**. Первый запуск требует интернет и примерно 2 ГБ свободного места.

Запускатор сам находит Python 3.10–3.13 x64 с Tkinter. Если подходящего Python нет,
скачивает подписанный установщик Python 3.13.17 с python.org и устанавливает его
в `.setup/python` без добавления в PATH. Затем создаёт отдельное окружение `.venv`,
ставит NumPy и SciPy с PyPI и CPU-версию PyTorch с официального сервера PyTorch.
При ошибке отсутствующих DLL устанавливает подписанный Microsoft Visual C++ Redistributable x64;
в этом случае Windows может запросить права администратора.

Модель загружается в `models/` с официального сервера Silero и проверяется по SHA-256.

При каждом запуске проверяются импорты библиотек, контрольная сумма модели и реальный
синтез короткой фразы без воспроизведения. При исправной установке интернет повторно не нужен.
Затем открывается окно приложения, а консоль запускатора закрывается.

**Только установка и диагностика:** `run.bat -CheckOnly`.
Журналы: `.setup/launcher.log` и `.setup/app.log`.
Если установка прервалась из-за сети, запустите `run.bat` повторно.
Если `.venv` повреждено, переименуйте эту папку и запустите `run.bat` снова.
Частично скачанная модель не заменяет исправный файл; при следующем запуске загрузка
начинается заново. Автоматическое обновление исходников с GitHub не выполняется.

Требования: Windows 10/11 x64. CUDA и видеокарта не нужны.

## Возможности

В простом интерфейсе: текст, голос, генерация, прослушивание, стоп и сохранение WAV.
Настройки простого режима: 48 кГц, обычный темп и тон, автоударения и «ё», обрезка тишины
с порогом −48 dBFS и запасом 100 мс, сглаживание 5 мс, без нормализации.
Расширенный интерфейс позволяет выбрать файл модели и изменить все эти параметры.
При возврате в простой интерфейс генерация использует стандартные настройки;
введённые расширенные значения сохраняются в полях до закрытия окна.

Список голосов проверяется по загруженной модели. По умолчанию `kseniya`.
Степеней «сложности модели» здесь нет: переключатель меняет доступность настроек интерфейса.
Темп и высота управляются через SSML. Исходный текст хранится отдельно без тегов.

Каждая генерация сохраняет в `output/` обработанный WAV, исходный `-original.wav`
и JSON с текстом и фактическими настройками. Кнопка «Сохранить WAV» копирует обработанный файл
в выбранное место. Длинный текст делится на фрагменты до 500 символов; максимум 20 000 символов.
В местах соединения фрагментов возможны дополнительные паузы модели.

Обрезка ищет тихие области только снаружи записи и сохраняет внутренние паузы.
Порог и запас можно менять; слишком высокий порог может затронуть тихие звуки.
Сглаживание уменьшает щелчки на границах. Нормализация меняет пиковый уровень, а не убирает шум.
Шумоподавление и автоматическое удаление лишних произнесённых слогов не реализованы:
у Silero TTS нет документированных параметров для такой обработки.
Слушайте оригинал и обработанный файл при подборе порога. Шумоподавление без необходимости
может ухудшить синтезированную речь, поэтому в базовую обработку оно не включено.

Можно выбрать другой доверенный локальный файл модели .pt в расширенном интерфейсе.
Запускатор автоматически обслуживает только стандартную модель из `models/`.

## Разработка

После `run.bat -CheckOnly`:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe tests\smoke_local.py
```

Для ручной установки сначала установите CPU-версию PyTorch по инструкции https://pytorch.org/get-started/locally/,
затем `pip install -r requirements.txt`. Основной путь установки — `run.bat`.
Веса модели, окружение, журналы и пользовательские дорожки не включаются в Git.
Условия сторонних компонентов перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).

Документация: https://github.com/snakers4/silero-models и https://github.com/snakers4/silero-models/wiki/SSML
