# Студия голоса · Silero V5

Локальное Windows-приложение: текст → WAV. По умолчанию использует **v5_cis_base под MIT**.
Лицензия разрешает коммерческое использование с сохранением уведомления об авторстве и лицензии.

## Установка

Скачайте ZIP из Releases, распакуйте и запустите **run.bat**.
Запускатор проверяет Python 3.10–3.13 x64 с Tkinter. Если Python нет, устанавливает подписанный
Python 3.13.17 с python.org в `.setup/python`, без добавления в PATH. Создаёт `.venv`, устанавливает
NumPy, SciPy и CPU PyTorch. При отсутствующих DLL устанавливает подписанный Microsoft Visual C++
Redistributable x64; Windows может запросить права администратора.

Скачивает `models/v5_cis_base.pt` (~88 МиБ), проверяет SHA-256 и выполняет синтез без воспроизведения.
Первый запуск требует интернет и около 2 ГБ свободного места. Исправная установка работает без сети.
Требования: Windows 10/11 x64, современный CPU с AVX2. CUDA и видеокарта не нужны.
`run.bat -CheckOnly` проверяет установку без открытия окна. Журналы: `.setup/launcher.log`, `.setup/app.log`.
При сетевой ошибке повторите запуск. При повреждении `.venv` переименуйте её и запустите снова.
Автоматического обновления исходников с GitHub нет.

## Модели

**v5_cis_base · MIT** — стандартная модель. 60 голосовых вариантов, 29 с префиксом `ru_` для русского.
По умолчанию `ru_zhadyra`. Автоударений и разрешения омографов нет.
Ставьте `+` перед ударной гласной: `Прив+ет! Провер+яем г+олос.`
Без разметки возможны ошибки произношения. Флажки автоударений и автоматической «ё» отключены.
Отдельный автоматический обработчик ударений не установлен. Даже `v5_cis_base_nostress` требует
размеченных ударений для русского, белорусского и украинского.

**v5_ru · некоммерческая** — прежние kseniya, xenia, baya, aidar, eugene и автоударения.
Доступна, если уже установлен файл `models/silero-v5_ru.pt`. Новый запускатор её не скачивает.
MIT-лицензия базовой модели на неё не распространяется.

## Интерфейс

Простой режим: модель, голос, текст, генерация, прослушивание, стоп и сохранение WAV.
Стандартные параметры: 48 кГц, обычный темп и тон, обрезка тишины при −48 dBFS,
запас 100 мс, сглаживание 5 мс, без нормализации. Расширенный режим открывает темп и тон
через SSML, частоту, обработку краёв и выбор .pt-файла. При возврате в простой режим
используются стандартные параметры.

Каждая генерация сохраняет в `output/` обработанный WAV, `-original.wav` и JSON с исходным текстом,
моделью и настройками. Текст не заменяется SSML-тегами. Максимум 20 000 символов; текст делится
на фрагменты до 500 символов. В местах соединения возможны дополнительные паузы.
Обрезка сохраняет внутренние паузы. Сглаживание уменьшает щелчки, нормализация меняет пиковый уровень.
Шумоподавление и удаление лишних слогов не реализованы. Исходная дорожка сохраняется для сравнения.

## Разработка и лицензии

После `run.bat -CheckOnly`:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe tests\smoke_local.py
```

Ручная установка: CPU PyTorch по https://pytorch.org/get-started/locally/, затем `pip install -r requirements.txt`.
